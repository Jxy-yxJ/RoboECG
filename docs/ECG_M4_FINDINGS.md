工具位姿链：`standoff = contact + n·(offset+60mm)` → `press = contact + n·(offset−4mm)`
→ `hold` → `retreat = contact + n·(offset+50mm)`，其中 offset=88 mm 为法兰到电极尖端
（场景工程参数）。每个航点用 M1 的接近方向阶梯规划（偏离法向 ≤30°，本次全部 0°）。

用的正是检测器路径。

## 6. 扰动评估（`scripts/m4_ecg_eval.py`，检测器路径）

11 个配置（5 维度），每次重建场景 → 渲染俯视深度 → 检测器 → 规则 → 与同配置的
GT 目标比较（隔离感知误差）。曲面源为**深度点云**（与 M3b/真实路径一致）。

| 配置 | 目标误差均值 (mm) | 最大 (mm) |
|---|---|---|
| baseline（标称场景） | 10.21 | 24.99 |
| 体型 0.90 / 1.10 | 9.12 / **19.11** | 14.09 / 37.26 |
| 手臂 60° / 90° | 10.21 / 10.21 | 24.99 / 24.99 |
| 呼吸 ±8 mm | 9.95 / 10.35 | 21.56 / 23.94 |
| 相机 ±4 cm | 9.61 / **15.31** | 21.44 / 36.95 |
| 患者 ±2 cm | **21.98** / 9.66 | 59.83 / 16.65 |

**结论**：
1. **最敏感维度是患者平移（+2 cm）与体型放大（1.10）**，最差均值 22 mm；
   呼吸与手臂姿态几乎无影响（手臂外展 60/90° 结果完全相同——手臂不遮挡躯干 landmark）。
2. baseline 10.21 mm 是该标称场景的单次抽样；M3b 的 60 样本分布均值为 **6.05 mm**
   （同一检测器/标定/规则），两者一致（10.2 落在该分布内）。
3. 误差 > 10 mm 的配置会触发 M4 的**闭环重贴**路径（阈值 10 mm，`MAX_ATTEMPTS=2`），
   这是扰动下的兜底机制。
4. 已尝试并否决的改进：把吸附点强制迭代到精确 (u,v)——网格路径变好但**深度点云
   路径变差**（6.05→8.7 mm，最大 31.7→62 mm），已回退（见 `ecg.py` 注释）。
