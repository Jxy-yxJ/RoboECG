## 1. 问题 1：单视角侧壁（V5/V6）

### 1.1 文献证据

| 方法族 | 代表工作 | 关键数字 | 对我们的意义 |
|---|---|---|---|
| 主动多视角传感 | Multi-View Active Sensing（arXiv:2403.12538） | 遮挡部位关键部件召回 69.2% → **90.1%** | 增加一个视角即显著恢复遮挡处感知——直接对应 V5/V6 侧壁 |
| 遮挡感知 NBV | OA-NBV（arXiv:2603.11072） | 目标观测成功率 >90%；关键点可见性 +≥58% | 视角选择的量化收益；可直接改造成"临床约束 NBV" |
| 腕相机 + 外部视角融合 | arXiv:2510.05536（eye-in-hand + eye-to-hand EKF） | 6-DoF 位姿/速度跟踪优于 SOTA | 现有融合只做"目标物位姿"，**没有做人体表面融合**（空白） |
| 腕相机局部重建 | RoboSeg（arXiv:2608.09778） | 部件级 mIoU 83.4% | 腕相机可独立完成接触邻域重建 |
| 电极多视角检测（真机路线） | El Ghebouli 2025（12 视角，ICP）、Bayer 2023（14 视角，2.0±1.5 mm） | 幻影 <2 mm；真人 2.61–5.78 mm | 闭环验证的真机对应方案（已在 v1 文献表中） |
| 深度补全（掠射/遮挡边界） | arXiv:2104.02253、arXiv:2306.03584、arXiv:1803.09326 | 在 NYU/KITTI/透明物上验证；**无人体皮肤 80°+ 掠射基准** | 掠射补全是公开空白：可作为数据集/基准类贡献 |
| 临床多视角先例 | 手术室多视角 RGB-D 位姿（arXiv:1701.07372） | 活体手术场景验证 | 临床多视角部署可行性 |
| AR 引导 ECG 贴放（人工） | 10.1186/1475-925X-13-153 | 体模 <3 mm、真人 <7 mm（人工操作） | 说明"引导式贴放"精度上限；**无机器人、无多视角闭环** |

### 1.2 方案（含创新点）

**I1（按压邻域腕相机融合，推荐首选）**：按压接近阶段用腕部 RGB-D 采集 V5/V6 侧壁局部点云，
与俯视点云在胸廓坐标系下配准融合（局部 TSDF/法向场对齐），作为融合阶段（M2）的侧壁表面源；
按压后同一腕相机复查电极。
- 创新性 caveat：最接近的工作是 arXiv:2510.05536（腕+外部视角位姿融合）与 RoboSeg（腕相机局部重建），
  均未做"人体表面接触任务的腕视角表面融合"；**本工作的差异点是解剖坐标系对齐 + 按压邻域表面源切换**。

**I2（多视角标签分离，解决视觉闭环 V5 未检出）**：用第二视角消歧仅 4 px 间距的 V5/V6 标记；
Isaac 提供视角一致的自动标注（可直接生成训练/验证数据）。
- 创新性 caveat：最接近的是多视角遮挡人体解析（arXiv:2509.10093，+4.2%），粒度是部件而非毫米级电极点。

**I3'（临床约束 NBV，可选）**：把 OA-NBV 的目标可见性打分扩展为"解剖 landmark 可见性 + 入射角 < 阈值"，
在 UR3 可达性/不回绕约束下选一个补盲视角。
- 创新性 caveat：最接近 OA-NBV（全身可见性，用于移动平台搜索），未做"机械臂对仰卧胸廓的 landmark 级补盲"。

### 1.3 落地清单（验收标准）

1. 在 `task_manager/` 增加第二相机渲染（腕部或侧面，Isaac 相机 prim + 外参标定）；
2. 新增 `scripts/m4_multiview_fusion.py`：俯视 + 侧视点云配准融合 → 在 V5/V6 局部区域与网格 GT 对比；
3. 验收：V5/V6 表面重建误差从当前 5–9 cm 降到 ≤1 cm；视觉闭环 V5/V6 从 5/6 → 6/6；
4. 不改变现有单视角结果（新路径标注 `perception_multiview`，与 v2 报告并列）。

**数据集核查（本会话实测）**：PhysioNet/CinC 2007 数据目录中只有 `case0003_b120.pts/b352.pts`
带电极其坐标；case0001/case0002 的 zip 是 **CT DICOM 影像**（无电极坐标），case0004_filtered.zip 同为 DICOM。

先前的建议（P0B §4 建议③）就此关闭；后续如需真实标注，应转向图 2.2 的替代路径。

### 2.2 方案（含创新点）

**I4（力/深度接触探测分类肋骨 vs 肋间，创新点，推荐）**：在 V2/V4 所在垂直线沿肋骨方向做
多点轻触探测（压入 1–2 mm、读取接触刚度/压深曲线），把"硬-软-硬"的周期特征作为肋骨水平证据，
把第 4 肋间锚定后在线校正 V1–V6 的纵向位置。
- 创新性 caveat：最接近的 arXiv:2507.20282 用触觉**映射肋骨点云**（体模），并未做
  "从接触响应分类肋骨/肋间并校正 ECG 电极行"；且**从未在人体验证**。本工作可先做仿真可行性 +
  体模协议设计，再谈临床。
- 需要的数值：肋骨（骨）与肋间肌/皮下组织的接触刚度对比。文献缺口：小压入下胸壁刚度无公开测量
  （T4 检索结论 G1）；本工作实验路线见 §2.3 的刚度标定。

**I4'（贝叶斯在线校正）**：以 SNND（已验证 −3.9 mm）钉住第 4 肋间行，以检测到的肋骨/肋间证据
更新落差先验 p(drop | 体型尺寸)，替代当前开环回归。
- 创新性 caveat：拓扑约束 MRI 方法（arXiv:2408.13945）与 US-CT 配准（T-ASE 2024）已做患者特异，
  但都不是"表面传感 + 在线更新"的形态，也不是机器人执行闭环。

**诚实策略（不依赖新传感）**：论文口径维持 v2 结论——落差回归报告为"GT 回归 ± 真实数据反例"，
不声称临床精度；仿真内把该不确定性纳入扰动评估（新增"落差 ±30 mm"配置），量化末端影响。

### 2.3 落地清单

1. `scripts/fit_drop_uncertainty.py`：把 P0b 的 −26.5 mm 反例转成先验区间（如 Laplace/Normal），
   更新 `configs/ecg_rules.yaml` 的 provenance 字段（`published_regression + real_patient_counterexample`）；
2. 扰动评估新增 `drop_bias ±30 mm` 两档（对齐 P0b），报告 V1–V6 末端位移与按压成功率；
3. 仿真内肋骨探测可行性：给患者碰撞体加"肋条"几何（简化 2 mm 脊 + 8 mm 周期）或改用真实体型

### 2.4 落差不确定性评估结果（本会话，规划级实验）

`scripts/m4_drop_bias_eval.py` → `runs/m4/drop_bias_report.json`。

用标准 approach ladder 重新规划（基座不重搜，caveat 已在脚本注明）：

| 附加落差 | 规划成功 | 失败电极 | 最小轨迹间隙（成功者） |
|---|---|---|---|

| 种子探针 `m4_v5v6_seed_probe.py`（18 种子：名义解 + 关节扰动 × 25 姿态） | IK 全部成功（450/450），但最好姿态仍穿透 **−17.4 mm（V5）/ −35.6 mm（V6）**；名义对照 **+49.6 / +56.5 mm** |

| **法向隔离（决定性）** `m4_v5v6_offset_curve.py` | 同一位置：**项目法向（二次曲面 patch 拟合）** +49.6/+56.5 mm ✓；**3 cm 线性 PCA 重拟合** −26.2/−35.8 mm ✗（δ=0 就失败） |
| 工具长度缓解 `m4_v5v6_mitigation_probe.py`（干净对比） | 0.088→0.12→0.15 m：偏移目标最差间隙 −35.6→−27.3→**−14.1 mm**；V5(−30 mm) 达 **+15.2 mm**（每 +30 mm 工具 ≈ +13 mm 间隙；单靠加长不能完全覆盖 V6） |

**修订后的结论**：

1. **±30 mm 的位置偏移本身可行**：保持项目自身法向求解时，偏移目标的间隙与名义几乎相同
   （+48–57 mm，330–345/375 命中）——落差回归误差对**执行层是可吸收的**（放置精度仍需 I4 校正，
   但不会再导致规划失败）；
2. **真正的风险因子是 V5/V6 的接触法向质量**：法向被 3 cm 线性 PCA 粗糙重拟合后，腕部-躯干间隙从
   +50 mm 跌到 −26 mm、直接不可行 ✗ → 项目现有的二次曲面 patch 拟合 + 守卫 + 先验角度门
   （`normal_angle_vs_prior_deg`）是关键；建议
   加显式"法向合理性门限"（偏离先验过大时拒绝/回退），并在多视角融合（§1.4）后复测侧壁法向；
3. 缓解选项：加长电极工具可线性增大侧壁间隙（每 +30 mm 工具 ≈ +13 mm 间隙），作为可选裕度；
4. 安全行为：不可行时规划**显式报错**（RuntimeError），不会静默错放 ✓。

> 方法学备注（诚实记录）：本节与 §2.4 的早期现象是用 3 cm 线性 PCA 重拟合法向构造"偏移目标"得到的；
> 该法向在侧壁不可靠，导致把"法向问题"误判为"位置问题"。法向隔离实验（δ=0 对照）推翻原判，
> 原表保留为下限证据；同时说明：**若多视角融合（§1.4）或其它新路径改变侧壁法向求解方式，必须重做本节的间隙复测**。

## 4. 问题 4：接触模型与力控（本会话已实现）

### 4.1 文献证据

| 主题 | 关键数字 | 来源 |
|---|---|---|
| 皮肤/软组织刚度 | 宏观 E ≈ 100–200 kPa（纤维网络）；微观 0.1–10 kPa；活体前臂吸盘法 E = 129±88 kPa、预应力 13.5±5 kPa | 10.1016/j.actbio.2023.08.030；10.1034/j.1600-0846.2000.006004214.x |
| 接触刚度换算（**估计**） | 平冲头 k≈2Ea/(1−ν²)：E=100–200 kPa、a=5–10 mm → **k≈1–4 kN/m**；当前模型 150 N/m 位于极软端 | 工程推导（非测量） |
| 力控架构 | 导纳/双力传感为标准（10.1007/s11548-017-1566-9）；QP 变阻抗 + 能量罐，力跟踪 RMSE 0.5–0.88 N | 10.1109/tim.2024.3372209 |
| 呼吸补偿 | 预测 + 视觉-触觉融合导纳（10.1109/tim.2025.3612625）；自回归预测 + 门控，运动 5–10 mm、16–18 次/分、误差 ↓≥89% | 10.1109/tuffc.2021.3075938 |
| 记录级方案 | 软体器械探头的力跟踪（2.5–15 N 量级） | arXiv:2410.03086 |

### 4.2 本会话实现（已通过测试）

**模块**：`robot_controller/compliant_press.py`
**评估**：`scripts/compliant_press_eval.py` → `runs/m4/compliant_press_report.json` + `compliant_press.png`
**测试**：`tests/test_compliant_press.py`（11 项；全套 47 项通过）

模型：1-D 准静态接触；真实压深 `u = clamp(i_cmd, −retract, depth_cap) + surface_error + residual_breathing`；
力 `F = k_true·max(0,u)`；力反馈 `i_cmd += K(F_target − F_meas)dt`，K 由期望时间常数 τ=0.05 s 与 k_est 决定；
按压期间深度相机持续跟踪胸壁（`residual_breathing_fraction` 建模跟踪残差）。

**结果（21 场景）**：

| 场景 | maxF (N) | maxDepth (mm) | RMSE (N) | 违规 |
|---|---|---|---|---|
| 位置控制 k150（v2 复现） | 1.80 | 12.0 | 0.65 | depth |
| 位置控制 k300 / k1000 | 3.60 / 12.0 | 12.0 | 1.37 / 5.20 | depth |
| 位置控制 20 次/分 12 mm | 2.40 | 16.0 | 0.98 | depth |
| 位置控制 +5 mm 感知误差 k150 / k2000 | 2.55 / **34.0** | 17.0 | 0.95 / 17.7 | depth |
| 力控 k50（软胸） | 0.40 | **8.0（封顶）** | 0.20 | 无（力亏欠已标记） |
| 力控 k75–k2000（6 档） | 0.60 | 8.0→0.3 | ≤0.001 | 无 |
| 力控 k_est 失配 0.5×/2×/4× | 0.60 | 4.0 | ≤0.001 | 无 |
| 力控 20 次/分 12 mm | 0.60 | 4.0 | 0.000 | 无 |
| 力控 +5 mm 感知误差 k150 / k2000 | 0.60 | 4.0 / 0.3 | 0.000 | 无（回退至 −4.7 mm 命令） |
| 力控 部分跟踪（残差 50%）k150 / k2000 | 0.647 | 4.31 / 0.32 | 0.033 | 无 |
| 力控 传感噪声 0.05 N | 0.635 | 4.24 | 0.011 | 无 |

**结论**：
1. 位置控制在 6/6 对抗场景违规（最差 17 mm/34 N）；力控 15/15 全部合规；
2. 力控把"感知误差"转化为**回退**（−4.7 mm 命令）而不是过压——与问题 1/2 的感知误差预算直接协同；
3. 唯一代价是软胸（k<75 N/m）时深度封顶造成力亏欠（0.4 N @ k=50），需**显式标记**而非静默；
4. 若真实胸壁刚度确为 kN/m 量级（§4.1 估计），位置控制的真机风险远大于 v2 报告数字。

### 4.3 落地清单（真机/仿真）

1. Isaac 执行链增加 `force_tracking` 模式（`execute_sequence` 的 press 段用本文环路替换定深按压），
   需要场景内 F/T 读数或按接触模型闭环（仿真）；真机以导纳控制实现；
2. 深度上限作为**硬约束**（命令侧钳制 + 力环），并保留 `i_cmd ≤ −retract` 允许回退；
3. 首枚电极（V1）做在线刚度估计，后续电极复用（k_est 自适应）——预期把 k_est 失配场景的 RMSE 再压低；
4. 若坚持位置控制（无传感器），则必须做呼吸相位门控（TUFFC 2021 路线），且不适用于 +5 mm 感知误差场景。

### 4.4 Isaac 执行链内验证（本会话实验）

`--force-tracking` 模式已接入 M4 执行链（`m1_demo.execute_sequence` 的 `force_track` 段：
守护式接近 + 力反馈保压 + 深度帽 + 回退；配置见 `m4_demo.py` 的 `FORCE_TRACKING`）：

```
./scripts/run_headless.sh scripts/m4_ecg_place.py --force-tracking --no-video
→ runs/m4/m4_report_force_tracking.json（PASS 6/6，min clearance 26.6 mm，1980 帧）
```

调试中发现并修复了两个真实工程问题（记录为工程结论）：
1. **深度帽语义**：力环最初把命令深度相对**名义表面**钳制，胸廓下落 8 mm 时无法跟随
   （接触丢失 66%）；改为相对**跟踪表面**（深度相机持续跟踪胸廓、命令跟随表面）后，
   深度帽约束的是皮肤压入量，而不是相对名义面的下潜量；
2. **IK 容差**：逐帧 IK 沿用规划默认容差（位置 5 mm / 姿态 0.2 rad）会产生毫米级漂移；
   力控内环改用 0.5 mm / 0.05 rad（法兰跟踪误差 ≤0.5 mm）。

| 指标 | v2 位置控制（呼吸） | v3 力控（呼吸，Isaac 内） |
|---|---|---|
| 最大压深 | 12.0 mm（超 8 mm 上限） | **4.28–4.46 mm** ✓ |
| 最大力 | 1.80 N（超 1.5 N 上限） | **0.64–0.66 N** ✓ |
| 违规电极 | 6/6 | **0/6** ✓ |
| 稳态力误差（末 2 s） | — | **RMSE 0.020–0.028 N**（F ∈ [0.54, 0.66]） |
| 执行到达误差（vs 命令位姿） | — | 0.10–0.85 mm |

与 §4.2 的数值网格一致：力控在数值层面 15/15 合规、Isaac 内 6/6 合规；位置控制在两个层面都违规。

## 6. 泛化分析：其他医疗检查项目（重点记录）

架构抽象（RoboECG 的可迁移主干）：

```
感知解剖 landmark（深度/学习）→ 解剖坐标系（临床规则锚定）→ 规则/距离表生成目标
→ 体表融合（表面约束 + 法向）→ 机器人接触执行（力/深度帽）→ 闭环验证与重放
```

### 6.1 候选任务对比（文献核实）

| 任务 | 已自动化程度（文献） | 最接近工作 | 距我们架构的差距 | 难度 |
|---|---|---|---|---|

### 6.2 推荐泛化目标（排序）

1. **EEG 10-20 贴放**（复用度最高：规则表 + landmark + 表面接触 + 验证；新增难点是毛发/耗材）；
2. **听诊点位**（复用度最高、难度最低；差异化 = 显式临床规则 + 仿真 + 力/深度帽；验证换成声学质量）；
3. **血压袖带**（白空间、临床量最大；需要新增"变形体环包"末端与手臂姿态感知）；
4. **静脉穿刺**（管线 1:1、已有 FDA 先例；难度与竞争最高，适合作为长期方向）；
5. **超声新器官**（同架构但竞争激烈；作为"规则引擎差异化"的对照场景）。

### 6.3 记录结论

- 上述泛化判断基于本会话 5 路检索（全部带 ID，可复核）；**"血压袖带"与"钼靶摆位"未检索到机器人工作**，
  属于可主张的白空间（投稿前仍须正式查新）；
- 复用成本最低的迁移路径是 **EEG 与听诊**：均可用同一冻结主干 + 更换规则表/验证模态；

**新指标首次运行发现（2026-09-29，多视角场景，PASS 6/6）**：此前被自引用口径掩盖的信息——
前胸/锁骨系 landmark 非常好（chest 0.1、pelvis 0.3、shoulder 0.5/0.6、clavicle 0.8/0.8、
neck_base 1.7、upper_chest 8.9 mm），而背侧脊柱系偏差大（spine_mid 50.3、neck_top 43.4、
spine_lower 121.6 mm）。

**2c 结论（同日封口）**：偏差大的背侧 landmark 是检测器的**合成填充值**
（`chest_detector.py` 从 pelvis/neck_base 外推），且 **`build_chest_frame` 不使用它们**——
frame 只用 chest/neck_base（up 轴）与锁骨（横向/原点）＝误差列表中最好的三项（0.1/1.7/0.8 mm）。
蒙特卡洛最坏情况敏感性（`scripts/m4_frame_sensitivity.py` → `runs/m4/frame_sensitivity.json`）：
按实测误差扰动这三项 → V6 处目标偏移最坏 **3.4 mm**（均值 1.3 mm，up 轴角 ≤0.49°）✓；
**反事实**：若 up 轴改用 neck_top−spine_mid（43/50 mm 误差），最坏目标偏移 **66.4 mm** ✗——
现有 frame 设计恰好避开该风险。**2c 关闭（无需修改）**。

**修订动作**：M4 感知报告此前的 `target_error_vs_mesh_gt_mm` 之名易被误读为"放置真值"；
2026-09-29 起代码与文档统一改名（`target_diff_vs_*_rules_*`）、新增上表 `metric_definitions`
字段与独立 landmark 误差；历史报告保留旧字段名供追溯。
