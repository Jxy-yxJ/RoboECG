# ECG M3b 结论：合成数据训练的胸部 landmark 检测器

日期：2026-09-19（同日规则修正后重跑评估，见 §v3）
执行环境：Isaac Sim 6.0.1（数据生成）+ PyTorch 2.11 / CUDA（训练与评估，Isaac env python）
**状态：PASS**：0 失败、端到端目标误差 **9.77 mm 均值**（目标 ≤10 mm，见 §v3）。

## 1. 结果

| 指标 | 值 |
|---|---|
| 数据集 | 220 个合成样本（俯视深度 320×180 + rig 关节投影标签），30 个留出验证 |
| 检测器 | 4 层 CNN（深度图 → 7 个 landmark 的归一化像素坐标），400 epochs，余弦调度 |
| 2D 像素误差 | **1.38 px 均值** / 4.75 px 最大（320 宽，约 **10 mm** 在胸壁深度处） |
| 各 landmark | 1.27–1.43 px（clavicle/shoulder/chest/neck_base/pelvis 均匀） |
| 坐标系轴向误差 | up **3.89°**、lateral **2.98°** |
| 坐标系原点误差 | du **−8.8 mm**、dv **+0.3 mm**、dn **+49.6 mm**（组织厚度，见 §4） |
| **V1–V6 目标误差** | **21.8 mm 均值** / 76.0 mm 最大；**生成失败 0/30** |
| M2 深度融合后 | 21.9 mm（深度已在感知路径内，融合无额外增益） |

**各电极误差（30 样本 × 6 电极）**

| 电极 | 均值 (mm) | 最大 (mm) | P90 (mm) |
|---|---|---|---|
| V1 | 19.9 | 49.3 | 33.7 |
| V2 | 19.8 | 59.5 | 32.2 |
| V3 | 17.9 | 58.5 | 30.3 |
| V4 | 22.1 | 76.0 | 33.2 |
| **V5** | **33.4** | 69.7 | 62.2 |
| V6 | 17.9 | 56.7 | 35.1 |

V5 最差（33 mm）：其横向位置 = 0.5×(锁骨中线 + 腋中线)，而腋中线取自体表轮廓，对轴向误差与边缘噪声最敏感。

## 2. 流水线（全感知路径，无 rig 关节、无资产网格）

```
俯视深度渲染（320×180）
  → CNN 检测 7 个胸部 landmark（clavicle L/R、shoulder L/R、chest、neck_base、pelvis）
  → 逐像素深度提升到 3D（stride=1 点云 57.6k 点）
  → 可感知 ChestFrame（up=肩中点→髋中点；lateral=肩线+髋线平均）
  → V1–V6 规则（M1 的已发表统计 + 实测参考线）
  → M2 深度融合（局部曲面先验，由深度点云拟合）
  → 与 GT（rig 关节 + 网格）对比
```

## 3. 关键实现要点（都有实测依据）

| 问题 | 现象 | 解决 |
|---|---|---|
| 关节在体内 | 标签是 rig 关节，深度测的是皮肤表面：3D 误差 96 mm（dn ≈ 5 cm 组织厚度） | 不影响 (u,v)：目标由 (u,v)+表面吸附定义，dn 被吸附吸收（见 §4） |
| 肩线噪声大 | 单用肩点的 lateral 轴误差 **12.0°** | 改为 **肩线 + 髋线平均** → **2.98°** |
| 手臂污染轮廓 | 深度点云中手臂垂在体侧，V6 的腋中线测到手臂外缘（v=0.41） | 用"躯干不可能比肩宽更宽"约束（可测 landmark） |
| 边缘吸附失败 | V6 位于躯干边缘，±2 cm 窗口点数不足（27/30 失败） | 自适应带宽（2 cm → 4 cm）→ **0 失败** |
| 低分辨率点云 | `depth_to_world_points` 默认 stride=2 使 320×180 退化为 160×90 | 评估用 stride=1（57.6k 点） |

## 4. 与 M3a 的对比（P1/P3 设计的验证）

| | M3a（MediaPipe 几何外推） | M3b（学习式检测器） |
|---|---|---|
| 坐标系原点误差 | **101.2 mm** | 52.5 mm（其中 dn=49.6 mm 是组织厚度，**对目标无影响**；有效平面误差 ≈9 mm） |
| 坐标系轴向误差 | up 1.2°、lateral 1.6°（需人工修正左右 + 逐像素提升） | up 3.9°、lateral 3.0°（**无需任何修正**） |
| V1–V6 生成 | **失败**（吸附点落在躯干外） | **0/30 失败** |
| 端到端目标误差 | 不可用 | **21.8 mm** |
| 原因 | 直立人先验，俯视仰卧属分布外 | 训练数据即来自本场景的俯视深度 |

结论：**P1（学习层放在解剖 landmark）+ P3（可感知坐标系）的路线得到验证**；M3a 的失败与 M3b 的可用性构成直接对照。

## 7. 局限与下一步

**局限**
- 端到端 21.8 mm 略超 M3 验收（≤20 mm）；V5 33 mm 为最差。
- 检测器仅用深度（未用 RGB 外观）；数据集为单资产 + 尺度/位置随机（无体型形状变化）。
- GT 是 rig 关节（仿真内部定义）；真实数据上需以外部标注（PhysioNet 躯干，见 M0 §9.5）或临床标准评估。
- 数据集与评估同源（同资产、同分布），未做跨资产/跨场景泛化。

**下一步（M3b v2 / M4）**
1. 检测器升级：热图（heatmap）输出 + 数据增广（噪声、遮挡）+ 更大数据集 → 目标 ≤10 mm。
2. 加入 RGB 输入（外观线索）与跨体型随机化（非均匀缩放/多角色）。
3. 把检测器接入 M4 执行链路（替换 GT landmark），并在 M4 的扰动评估中作为"感知路径"统计。
4. 用 PhysioNet 真实躯干做离线定位验证（M0 §9.5 已落地数据）。

## v2 的关键修正（每一步都有实测依据）

| 问题 | 现象 | 修正 |
|---|---|---|
| U-Net 跳跃连接尺寸不匹配 | 180→45→22 vs 45 崩溃 | 改用 `F.interpolate(size=skip.shape)` |

| 标定用错参考点 | 用体表肩点导致过校正（误差 25.4 mm） | 改用体表**锁骨点**（与坐标系原点定义一致）→ 15.4 mm |
| 训练/评估报告不匹配 | 读错 train_report | 按模型类型选择报告 |

## 剩余误差（如实）

- 原点 du 残余偏差已降到 −4.1 ± 4.6 mm，不再是主因（相关 −0.03）。
- **V5 是唯一显著离群（21.6 mm）**：其横向位置 = 0.5×(锁骨中线 + 腋中线)，而腋中线取自体表轮廓的 98 分位，对坐标系 u/轴向残差与点云边缘噪声最敏感。
- 下一步（M3b v3 / M4）：V5 改为由**检测器直接回归腋前襞 landmark**（而非从轮廓推算）；再把检测器接入 M4 执行链路并在扰动评估中统计。


## v4 结果（数据集重生成 + 手臂随机化 + 逐 landmark 标定，2026-09-19）

### 为什么要重做（v3 的结论在手臂姿态改变后失效）

M1 的 V6 修复要求患者左臂**外展 75°**（否则手臂挡住腋中线）。旧数据集（600 样本）
的手臂全部贴放，与新场景存在域差；且手臂姿态本身在真实场景中可变。

**处理**：
1. 数据集**重新生成**（600 样本，同一 seed）：新增 `arm_abduction_deg ∈ [60°, 90°]`
   均匀随机（生成仅 ~1 s/样本，58 s 完成全量）；
2. 检测器**重新训练**（200 epochs，val 像素误差 0.13 px）；
3. 评估暴露并修复一个**真问题**：预测 landmark 是深度**提升到皮肤**的点，GT 是
   **体内关节**，二者的横向分量差异使 `v_shoulder`/`v_mcl` 系统性偏小 6–9%，
   宽度测量被限幅截断 → 落差偏小 → V4 误差 28 mm（V3/V5 受连带）。

**修复（训练集标定，无泄漏）**：逐 landmark 标定 `(du, dv, dn)` 偏移并施加于预测点；
同时**移除冗余的原点标定**（原标定把原点移到皮肤，与 landmark 标定重复校正，实测
两者叠加反而更差：9.59 → 6.05 mm）。

标定出的偏移物理可解释（n 分量即组织深度）：clavicle 49 mm、shoulder 81–83 mm、
chest 134 mm、neck_base 117 mm、pelvis 141 mm；shoulder 的横向分量 ±13 mm
（正是 V4 误差的来源）。

|---|---|---|
| 数据集 | 600（手臂贴放） | 600（手臂外展 60–90° 随机） |

| 坐标系原点误差 | 7.7 mm | **8.6 mm** |
| **V1–V6 目标误差（均值）** | 9.77 mm | **6.05 mm** |
| 最大 | 35.8 mm | 31.7 mm |
| 融合后（M2 路径） | 9.86 mm | **6.14 mm** |
| 生成失败 | 0/60 | **0/60** |

**各电极（v4，均值/最大 mm）**：V1 7.1/19.6、V2 7.1/19.7、V3 4.6/13.0、V4 6.3/31.7、
V5 5.8/18.3、V6 5.6/16.5。误差结构：V1/V2 由坐标系原点误差主导，V4/V5 由 up 轴旋转
噪声主导（见 v3 归因表）。

## v3 结果（规则修正 + 旋转标定后重跑，2026-09-19）

### 数据集是否需要重新生成？—— 不需要（已核实）

`runs/m3b/dataset/*.npz` 的标签是 **7 个 rig 关节的像素/3D 坐标**（`pixels`、`world_points`），
**不含电极位置**；电极由评估脚本在推理时用规则现场生成。因此：

| 资产 | 是否受规则修正影响 | 处理 |
|---|---|---|
| 数据集（600 样本） | 否（标签=landmark，与规则无关） | 保留，未重新生成 |
| 检测器权重 | 否（学 landmark） | 保留，未重新训练 |
| 评估脚本 | **是**（内部用规则生成 GT/预测目标） | **已重跑** |

> 注：`scripts/m3b_ecg_detector_eval.py` 内 `generate_v1_v6(gt_landmarks, gt_frame, points, rules)`
> 与 `generate_v1_v6(pred_landmarks, pred_frame, points, rules)` 均使用当前
> `configs/ecg_rules.yaml`，所以重跑评估即完成规则切换。

### 新发现：坐标系旋转的系统性偏置（已标定）

按逐样本的有符号旋转分解（本次新加，见 `eval_report.json → per_sample[].frame`）：

| 分量 | 均值 | std | 判定 |
|---|---|---|---|
| **up 绕 lateral 倾斜（前向）** | **−3.26°** | 1.67° | **系统性偏置，可标定**（|均值|/std=1.96） |
| up 绕 anterior 倾斜（侧向） | +0.08° | 0.16° | 无 |
| lateral 其余分量 | ≈0° | ≤1.3° | 无 |

**根因**：预测 landmark 经深度**提升到皮肤表面**，而 GT landmark 是**体内关节中心**
（rig joint），二者方向系统性不同 → 坐标系 up 倾斜（原点偏移早已由 dn −49.8 mm 标定吸收）。

**修正**：与原点标定同协议，在**训练集**上估计 pred→GT 的平均旋转（4.33°）并取反施加于验证集坐标系。

| 生成失败 | 0/60 | 0/60 | **0/60** |

### 剩余误差归因（相关性，60 样本）

| 电极 | 与原点误差相关 | 与 up 旋转相关 | 主要来源 |
|---|---|---|---|
| V1/V2 | **+0.96 / +0.95** | +0.13 | 坐标系原点（7.7 mm） |

下一步（若要 <5 mm）：① 原点/旋转标定改为**随体型缩放**（当前为常数，体型 0.88–1.12 变化下残差 4 mm）；
