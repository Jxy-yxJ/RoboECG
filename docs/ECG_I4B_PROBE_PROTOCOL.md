# I4-b：真机肋间探测协议设计（M5 方案）

日期：2026-10-01。依据：I4-lite 幻影研究（`runs/m4/rib_probe_study.json`）、I4-a 接入
（`farus_ecg/target_localization/rib_probe.py`，`runs/m4/probe_correction_demo.json`）、
力控模块（§4.4，Isaac 内 6/6 零违规）。本文件是 roadmap 6c 的交付物。

## 1. 目标与动机

V4/V5/V6 的纵向位置来自人群回归（SNND − 拟合落差）。两个真实反例：

- P0B 真实患者：回归**高估 26.5 mm**（`docs/ECG_P0B_FINDINGS.md`）；
- 工程肋条幻影：躯干宽 0.38 m 时回归误差 **+42.26 mm**（真值行距 48 mm）。

幻影研究证明：**轻触扫描把行距误差从 ~42 mm 降到 0.75 mm**，且不依赖深度分辨率
（工作分辨率下 5 mm 肋脊 ≈0.7–1.2 px，去趋势残差 7.5–11.7 mm，不可用）。

## 2. 通道选择：接触 vs 超声

| 通道 | 证据 | 结论 |
|---|---|---|
| **接触力扫描** | 幻影 6 组参数（κ∈{1.5,3,10} × 行程 {1,2} mm）**全部一致检出 48.75 mm**；复用现有力控（τ=0.05 s、稳态 RMSE ≤0.03 N） | **主线**（无额外硬件） |
| 深度扫描 | 工作分辨率下不可分辨 5 mm 肋脊（残差≈噪声底）；理想深度通道上界 0.45 mm 仅作对照 | 排除 |
| 超声 | 可直接分辨肋骨/软骨/间隙，但需探头+耦合+采集链，未仿真 | M5+ 备选（需临床合作） |

## 3. 协议参数（由幻影外推）

| 参数 | 取值 | 依据 |
|---|---|---|
| 扫描线 | 锁骨中线（v = v_mcl，由 chest frame 给出）；备选胸骨旁线 | 幻影口径；胸骨旁更平、κ 对比更好 |
| 采样 | **13 点 @ 5 mm**（覆盖 ICS3–ICS6，两端各留 1 点余量）；可先粗后细 | 幻影 41 点冗余；点距 < 肋带半宽 11 mm |
| 行程 | 1.0–1.5 mm（轻触） | 幻影 1–2 mm 全一致；目标力 = k_skin·stroke ≈ 0.2–0.5 N |
| 力上限 | **1.0 N**（硬限） | 患者安全；远低于按压 0.65 N 的疼痛阈值经验 |
| 驻留 | 每点 0.5 s + 稳定判据（相邻 50 ms 力变化 <0.02 N） | 力控整定（τ=0.05 s） |
| 点间运动 | 抬离 5 mm → 平移 → 下压，20–30 mm/s 守护式 | 复用 M1/M4 序列 |
| 预估耗时 | 13 点 × ≈1.1 s ≈ **15 s/患者** | 成本估计（首版） |

## 4. 在线估计器（已实现）

1. `classify_rib_bands(u, force)`：高力带（阈值 = 低分位 + 0.5×(高分位−低分位)）→ 加权带中心；
2. `estimate_ics_rows(...)`：ICS4 = 最接近 SNND 先验的带中点；ICS5 = 其下相邻中点；
3. **质量门**：检出带数 ≥3；相邻带间距落在 35–60 mm 生理范围；不满足 → 优雅回退到人群回归
   （不改变现状，只是不加分）；
4. 输出 `u_5ics_override` → `generate_v1_v6(u_5ics_override=...)`，provenance 标注
   `probe_corrected`（已接入，V4 −42.4→−0.3 mm 等见 I4-a 表）。

## 5. 验收（M5）

| 项 | 门槛 |
|---|---|
| 行距准确性 | 与超声/CT 对照 ≤3 mm；或与临床标尺 ≤5 mm（幻影 0.75 mm 不可直接外推） |
| 重复性 | 3 次扫描的 ICS5 散布 ≤2 mm |
| 安全性 | 峰值力 ≤1 N；无误触痛反馈即停 |
| 时间 | ≤30 s/患者（首版预算 15 s） |

## 6. 风险与缓解

| 风险 | 缓解 |
|---|---|
| 软组织上覆/滑动（κ 低） | κ≥1.5 已够（幻影）；不足时增行程至 2 mm（力仍 ≤1 N）或换胸骨旁线 |
| 呼吸运动（±8 mm） | 力控跟踪 + 相位门控（§4）；探测全程按力控制，不按位置 |
| 患者不适 | 轻触 ≤1 N、≈15 s；可暂停 |
| 体毛/衣物 | M5 假设直触皮肤；遇到则记录并转超声路线 |
| 肋间距异常（桶状胸等） | 估计器按实测行距工作，不依赖回归——这正是本模块的价值 |

## 7. M5 落地清单

1. 真机扫描控制器（新）：点列生成 + 力稳定判据 + 数据落盘；
2. 复用力控执行层（`compliant_press`）与抬离-移动-下压序列（M1）；
3. 分类器阈值/κ 的实机标定（首周数据）；
4. 对照数据获取（超声/CT 或临床标尺，外联）；
5. 与 I4-a 规则链接通（`u_5ics_override` 已就绪，含测试）。

## 8. 诚实边界

- 幻影是工程构造（5 mm 肋脊、参数化 κ、无真实软组织滑动与肋骨力学）；
- 探针精度未在真机验证；耗时/接受度为估计值；
- 超声路线未评估（未仿真）。
