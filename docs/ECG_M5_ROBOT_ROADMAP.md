# M5 真机路线设计：F/T、导纳与门控（roadmap 8）

日期：2026-10-01。依据：力控模块与 Isaac 内验证（§4.4：6/6 零违规、按压 0.64–0.66 N、
压深 4.28–4.46 mm、稳态 RMSE ≤0.03 N、呼吸 ±8 mm@15/min 下无违规）、I4-b 探测协议
（`docs/ECG_I4B_PROBE_PROTOCOL.md`）、扰动鲁棒性刷新（11 配置，最差 9.01 mm）与
§4.1 文献（QP 变阻抗+能量罐 RMSE 0.5–0.88 N；预测+视觉触觉导纳；自回归预测+门控
运动 5–10 mm、16–18 次/分、误差 ↓≥89%）。

## 1. 架构总览

```
感知（相机+检测器） → 规划（规则链+探针校正） → 执行（导纳力控按压）
     ↑                                             ↓
视觉闭环 I2 ←—— 监控（F/T + 运动学 + 视觉） ←—— 异常门控（重规划/回退）
```

仿真已验证的组件（直接移植）：`compliant_press`（1-D 接触模型+比例力环）、
抬离-移动-下压序列、守护式接近（standoff 33 mm）、探针决策层（I4-a/b）。

## 2. 硬件：F/T 与采样

| 项 | 建议 | 依据 |
|---|---|---|
| 传感器 | 腕部 6 轴 F/T（如 ATI Mini40 级） | 力环需要法向分量；6 轴兼顾切向监控 |
| 采样率 | 1 kHz 采集、≥100 Hz 控制 | 接触检测去抖；τ=0.05 s 环路只需 20 Hz |
| 工具 | 电极按压头 + 可选探针头（I4-b） | 同一接口两用 |
| 触觉阵列 | 可选（M5+） | 肋骨定位可替代探针（未评估） |

## 3. 导纳/力控

1. **轴选择导纳**：按压沿工具轴 1-D 导纳（仿真同构），侧向/旋转由位置控制保持；
   接触意外侧向力 >0.5 N → 立即抬离并重规划（仿真未覆盖，真机必须加）。
2. **在线刚度估计**：触时按 F/u 斜率估计 k_skin（仿真标称 150 N/m）；
   力环增益按 τ=0.05 s 与 k_est 调度（`K = 1/(τ·k_est)`，已实现）。
3. **安全层**（优先级从高到低）：力上限硬限（1.0 N，超限即退）→ 速度上限
   （20–30 mm/s）→ 守护式接近（接触前 33 mm 停）→ 软件急停钩子。
4. **漂移/摩擦**：轻触段（≤2 mm 行程）切向风险最低（I4-b 用此）；按压段
   轴向为主、切向监控。

## 4. 呼吸门控

- 仿真结论：**力跟踪本身已足够**——±8 mm@15/min 呼吸下力 0.64–0.66 N、压深
  4.28–4.46 mm、零违规（力环把呼吸当作扰动吸收）；无需呼吸预测即可达标。
- 真机增量（可选裕度）：若临床呼吸幅度更大（>±10 mm）或患者咳嗽，启用
  ① 自回归预测（文献：误差 ↓≥89%）或 ② 相位门控（仅在呼气平台按压）；
  门控信号：F/T 低频分量（0.2–0.4 Hz 带通）或视觉胸廓跟踪（俯视相机已有）。
- 异常门控：|F| 超限、力环饱和、胸腔运动相位突变 → 暂停 → 等待 → 重试/重规划。

## 5. 监控与异常恢复

| 监控项 | 阈值 | 动作 |
|---|---|---|
| 力跟踪误差 | 稳态 >0.1 N 持续 1 s | 暂停、冻结、重试一次 |
| 峰值力 | >1.0 N | 立即抬离，记录，人工确认 |
| 视觉复检 I2 | 落点偏移 >3 mm | 重规划该点（复用多视闭环） |
| 接触丢失（F≈0 但压深命令在下） | 持续 0.2 s | 视为皮肤滑移/悬空 → 回退重试 |
| 运动学/可达 | IK 失败或间隙 <20 mm | 重选基座/工具（加长探针 0.088→0.15 m，间隙每 +30 mm ↑≈13 mm） |

## 7. 风险与缓解

| 风险 | 缓解 |
|---|---|
| 患者运动/咳嗽 | 门控（§4）+ 力上限硬限 + 人工监督（首例） |
| 软组织非线性/粘滑 | 在线 k_est + 低行程轻触（探针）；按压段慢速 |
| 传感器漂移/温漂 | 每次接触前零偏校准（抬离时） |
| 体表差异（体毛/敷料） | 记录并转可选路线（I4-b 超声） |
| 仿真-真机摩擦差异 | 切向力监控 + 轴选择导纳（§3.1） |
