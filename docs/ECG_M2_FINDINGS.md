# ECG M2 结论：RGB-D 深度融合与局部法向先验

日期：2026-09-18（2026-09-19 修正规则后重跑）
执行环境：Isaac Sim 6.0.1，RTX 4060 Laptop 8GB
**状态：PASS**（命中率 1.00；位置误差均值 **1.02 mm**；实测法向与网格差 ≤**8.49°**；法向接受率 1.00）

> 2026-09-19 重跑说明：目标规则经独立真值修正（V4–V6 下移 ~56 mm），吸附改为局部 PCA 切平面二次拟合
> （V5/V6 处旧 (u,v) 参数化拟合 RMS 达 16–25 mm、法向不可信，已修）。重跑结果见下表。

## 0b. 修正说明（2026-09-19 第二轮：掠射回退 + 验收口径）

V6 修正到真实腋中线后，俯视相机对该处是**掠射角 ≈70°**：深度射线与表面近乎平行，
小的深度误差会造成厘米级横向位移，局部 PCA 法向也不可靠（实测融合后位置差
49.7 mm、法向差 44.5°，而"vs 局部先验"仍显示 12.7° 通过——先验在侧壁同样退化）。

**修复**：`fusion.py` 增加入射角判据（`max_incidence_deg: 65`），超过则**不做深度测量、
直接保留模型目标**（并记录 `reason=grazing_incidence`）。验收口径相应改为
`valid_rate == 1.0`（每个目标都有可用位姿：深度或正当回退）+ 位置/法向误差界限；
深度命中率仍报告但不强制 1.0。

**第二轮重跑（PASS）**：valid_rate **1.00**；位置误差均值 **1.12 mm**（最大 4.63）；
融合法向 vs 网格均值 **0.89°**（最大 2.18）；回退目标：V6（掠射，正当回退）。

## 3. 方法

```
网格目标（M1）+ 拟合胸廓曲面先验（4 阶多项式 n=f(u,v)，RMS 5.31 mm）
  → 俯视 RGB-D 渲染（1280×720，垂直 aperture 已修正使 fx=fy）
  → 逐目标：
      投影到深度图 → 3px 中值深度 → 皮肤点（沿相机射线径向修正）
      → 12px 窗口 PCA 法向（r=3cm，朝向相机）
      → 约束：皮肤点距名义目标 ≤5 cm；实测法向 vs 局部先验 ≤25°
      → 通过则采用深度测量；否则回退名义目标/法向（并记录原因）
```

- 位置与法向的每次接受/拒绝都记录在 `m2_report.json → targets[].info`。
- 先验模型：`roboecg/perception/torso_prior.py`（对资产网格前胸拟合，provenance=`asset_measurement`，附 RMS 供审计）。
- 融合：`roboecg/target_localization/fusion.py`；参数在 `configs/ecg_rules.yaml → depth_fusion`（`engineering`）。
- 单测：`tests/test_ecg_fusion.py`（合成深度图；命中/回退/越界/法向拒绝/评价），共 24 tests 全过。

## 4. 误差解读（如实说明）

- 网格目标（M1）在仿真里**就是**地面真值定义（它落在资产网格表面上），所以"位置误差"衡量的是**真实感知路径（深度）相对 GT 引入的误差**，不是相对 M1 的改进。
- 误差来源：深度渲染的离散化（俯视 ~1.1 m，1280×720）、中值窗口、PCA 法向拟合。最大误差 V6 = 2.63 mm 出现在侧胸（掠射角、有效点少：267 个内点 vs V1 的 664 个）。

## 7. 局限与下一步

**局限**
- 仿真深度为理想渲染，无真实传感器的噪声/量化/多路径；真机需要标定与滤波。
- 曲面先验拟合自同一资产网格（仿真内部一致），真实路径需由检测器/拟合给出（M3b）。
- 仅在 scale=1.0 体型上验证（M0 的体型族扫描只覆盖几何与可达性）。
- 25° 接受阈值与 5 cm 位置界仍是工程参数（已标注 provenance）。

**下一步（M3）**
1. **M3a**：MediaPipe 33 关键点 → 可感知 ChestFrame（肩/髋/耳 + 人体测量外推），评估与 GT 坐标系的差距。
2. **M3b**：用 Isaac 合成数据（多体型/姿态/光照）训练**解剖 landmark 检测器**（P1），替代 rig GT landmark；先验曲面改由检测器输出拟合。
3. 目标纵向仍依赖 SNND 统计与 2 cm 肋间假设 → M3b 的学习模型是替换路径（见 M1 §2）。
